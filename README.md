# DerEisenSpawn — Module 1: Gameplay Project Assignment

A CoD Zombies-style project built in Unity.

## Tech
- **Unity Version:** (e.g., 2022.3.40f1) – see `ProjectSettings/ProjectVersion.txt`
- **Render Pipeline:** (URP/HDRP/Built-in)
- **Platforms:** Windows (planned WebGL?)

## Getting Started
1. Clone repo
2. Open the project in the matching Unity version
3. Open `Assets/Scenes/<YourMainScene>.unity`
4. Press Play

## Controls
- WASD: Move
- Mouse: Look / Shoot
- R: Reload
- F: Interact / Buy
- Esc: Pause

## Project Structure
- `Assets/Scripts/` – gameplay code
- `Assets/Prefabs/` – enemies, weapons, etc.
- `Assets/Scenes/` – levels (e.g., DerEisen)
- `ProjectSettings/` – Unity project settings
- `Packages/` – package manifest/lock
